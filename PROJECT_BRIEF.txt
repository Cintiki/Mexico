PROJECT: Mexico Dice Game — Sprite-Based Web Game

We are building a web-based version of the dice game Mexico.

The game should be built as a browser game using HTML, CSS, and JavaScript, or a modern web framework if already present in the project.

The interface should use the supplied art assets and sprite sheets.

The art style is black-and-white, hand-inked, vintage cartoon / arcade mascot style.

Do not redesign the game visually.
Do not create new character designs.
Use the art assets exactly as provided.
The UI boxes, buttons, panels, score rows, and input fields should be built with CSS, not image files.
The supplied image assets are for branding, dice, character portraits, event cards, icons, props, and sprite animation.

============================================================
GAME RULES
============================================================

Always exactly 4 seats.

Each player starts the overall session with 3 coins.

Each individual game:
- Every active player antes 1 coin into the pot at the start of the game.
- If a player has 0 coins, they cannot enter another game.
- The pot equals the sum of all antes for that game.
- Winner of the game collects the pot.

Strikes:
- Each game uses 5 strikes.
- A player who loses a round receives strikes.
- The first player to reach exactly 5 strikes gets one final chance called “Ride the Bus”.
- The Ride the Bus player wears the sombrero.
- Use the character’s bus static sprite:
  mexico_[character]_bus_static.png
- Use event_ride_the_bus.png or icon_sombrero_status.png as status marker.
- If that player loses again, that player is out.
- Any later player who reaches 5 strikes is immediately out and does not get Ride the Bus.
- Only the first player to reach 5 strikes in that game gets Ride the Bus.

Important Ride the Bus rule:
A player only gets to Ride the Bus if they are the first player to reach exactly 5 strikes.
If a player jumps past 5 strikes because of a heavy Mexico penalty, they are eliminated immediately and do not get Ride the Bus.

Example:
Player has 4 strikes.
They lose a normal round and receive 1 strike.
They now have exactly 5 strikes.
If nobody has used Ride the Bus yet, this player now rides the bus.

Example:
Player has 4 strikes.
They lose a round with a 2-strike Mexico penalty.
They now have 6 strikes.
They are eliminated immediately.
They do not get Ride the Bus.

============================================================
MEXICO PENALTY
============================================================

Mexico is the roll 2 and 1.

If a Mexico roll, 2-1, is rolled during a round, the losing player receives 2 strikes instead of 1.

Multiple Mexico rolls in the same round stack by +2 each time.

Penalty table:
0 Mexicos in round = loser takes 1 strike
1 Mexico in round = loser takes 2 strikes
2 Mexicos in round = loser takes 4 strikes
3 Mexicos in round = loser takes 6 strikes
4 Mexicos in round = loser takes 8 strikes

It is possible for a player to be knocked out in the first round if enough Mexico rolls happen.

Tie-breaker rolls do not count as Mexico rolls.
One-die tie-breakers do not increase the Mexico penalty.

============================================================
ROUND RULES
============================================================

Each round has a starting player.

The starting player may roll two dice up to three times.

The starting player may stop after:
- 1 roll
- 2 rolls
- 3 rolls

The number of rolls used by the starting player becomes the maximum number of rolls every other player may use during that round.

Examples:
If the starting player rolls once and stops, every other player gets only 1 roll.
If the starting player rolls twice and stops, every other player may roll up to 2 times.
If the starting player rolls three times, every other player may roll up to 3 times.

Only the final roll counts.

If a player chooses to roll again, they must roll both dice.
Players cannot keep one die and re-roll the other.

After every active player has taken their turn:
- highest final roll is the round winner
- lowest final roll is the round loser
- round loser receives strikes
- round winner starts the next round

If there is a tie for lowest, resolve with a one-die tiebreaker until only one loser remains.

If there is a tie for highest, resolve with a one-die tiebreaker until only one winner remains.

All ties must be resolved with one die.
No shared round winners.
No shared round losers.
No shared game winners.

============================================================
DICE RANKING
============================================================

Use this ranking from strongest to weakest:

1. Mexico = 2-1
Highest roll.
Also triggers Mexico penalty for the round.

2. Doubles
6-6 is highest double
then 5-5
then 4-4
then 3-3
then 2-2
then 1-1

3. Normal rolls
Highest die first, lowest die second.

Example:
6-5 beats 6-4
5-4 beats 5-3
4-2 beats 3-2

Important:
Always sort normal roll dice high-to-low for comparison.
But Mexico is specifically 2-1 and is the highest special roll.

Suggested rank values:
31 = 1
32 = 2
41 = 3
42 = 4
43 = 5
51 = 6
52 = 7
53 = 8
54 = 9
61 = 10
62 = 11
63 = 12
64 = 13
65 = 14
11 = 15
22 = 16
33 = 17
44 = 18
55 = 19
66 = 20
Mexico / 21 = 21

Suggested roll value function:
If dice are 2 and 1:
  return rank 21, label "Mexico", isMexico true

Else if dice are doubles:
  return rank 14 + die value

Else:
  sort dice high-to-low
  convert to two-digit value
  use the rank table above

Comparison:
Mexico beats doubles.
Doubles beat normal rolls.
Within doubles, higher double wins.
Within normal rolls, higher rank wins.

============================================================
TIEBREAKERS
============================================================

All ties are resolved with ONE die only.

Normal two-dice Mexico scoring is not used for tie-breakers.

Start order tie:
- tied players roll one die
- highest single-die roll wins
- if still tied, repeat among tied players only

Round loser tie:
- tied lowest players roll one die
- lowest single-die roll loses
- if still tied, repeat among tied players only
- final result must be one loser

Round winner tie:
- tied highest players roll one die
- highest single-die roll wins
- if still tied, repeat among tied players only
- winner starts the next round

Game winner tie or final ambiguity:
- resolve with one die until only one winner remains

Use:
assets/events/event_tiebreaker.png
assets/icons/icon_tiebreaker_die.png

COIN / POT SYSTEM
============================================================

Each player starts the session with 3 coins.

At the start of each game:
- every participating player pays 1 coin into the pot
- pot increases by 1 per participating player
- if a player has 0 coins, they cannot participate in the next game

At end of game:
- last active player wins the game
- winner collects full pot
- add pot to winner coin count
- set pot to 0
- show assets/events/event_game_winner.png
- show assets/props/prop_coin_burst.png if useful

Session winner:
- When only one player has coins remaining, they are the session champion.
- Show assets/events/event_session_champion.png.

============================================================
NPC / AUTO PLAY
============================================================

NPC players should use simple readable logic.

Suggested NPC behavior:
- Roll at least once.
- If NPC is first player, NPC may randomly hold after 1, 2, or 3 rolls.
- If chasing a current best roll:
  - If NPC beats the current best roll, hold.
  - If not and rolls remain, continue.
  - If out of rolls, stop.
- Use short pauses between NPC actions so the player can follow what happened.
- Use dice animation for NPC rolls too.
